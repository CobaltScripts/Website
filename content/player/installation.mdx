# Installation

Cobalt is a Fabric mod for Minecraft. Getting it set up takes just a few minutes.

## Prerequisites

- Minecraft Java Edition
- Fabric Loader installed

## Steps

1. **Install Fabric** if you haven't already. Download the installer from the Fabric website and run it, selecting the Minecraft version you play on.

2. **Download Cobalt** from the [GitHub releases page](https://github.com/CobaltScripts/Cobalt/releases). Grab the latest `.jar` file.

3. **Place the jar** in your Minecraft `mods` folder

4. **Launch the game** with the Fabric profile selected. Cobalt will load automatically.

## Verifying it works

Once in-game, open chat and type `.cobalt`. The config GUI should open. If it does, you're all set.

## Updating

Replace the old jar in your `mods` folder with the new one. Your settings are stored separately in `config/cobalt/` and won't be lost.

## Where files live

All of Cobalt's files (config, addons, themes) are stored under `config/cobalt/` inside your Minecraft directory.
